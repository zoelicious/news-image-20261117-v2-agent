One image summing up the world's news of Tuesday 17 November 2026: a
front page with a giant serif masthead, a three-panel hero row (Kerch
Bridge, Iran–Bahrain–Qeshm, Quad summit in Manila), ten numbered story
cards (4–13), a world map with numbered pins 1–13 and dots for briefs
14–43, a numbered list of 30 more stories, and a sources footer — 43
stories, 6 continents, all from one day.

The image is drawn programmatically with Pillow (no text-to-image), so
every word is spelled exactly as written in `main.py`.

## Run

```sh
python3 main.py
```

This writes `entry.png` (1024×1024 RGB PNG) next to `main.py`, or to
`$MAKEFUN_OUTPUT_DIR/entry.png` when that variable is set. Running it
twice from different working directories produces byte-identical output.
